Записка для того, кто выкладывает. Всё ниже уже сделано в ветке `claude/thailand-fishing-tours-vjkxkt`; осталось выложить и проверить.

## Решения владельца

- На erkak.com — **экосистема ERKAK** (`wellness/`). Магазин переезжает в `/var/www/erkak.com-shop` и не удаляется.
- Контакты на сайте: WhatsApp и Telegram **+998 99 050 50 70**. Почты пока нет — поле `email` пустое, на сайте её не видно.
- Обещания ERKAK Private (ответ за 15 минут в рабочее время, план за 24 часа, 24/7 во время поездки, NDA по запросу) утверждены.

## Что выкладывается

- 9 языков: ru, en, de, ar, zh, ja, ko, th, uz — 1 323 страницы, около 80 МБ.
- API заявок и оплаты: `wellness/server/leads.mjs`, служба `erkak-wellness` на 127.0.0.1:8796. Нужен Node 22.13+ на сервере (`node:sqlite`).
- Перед выкладкой локально и в CI проходят: `STRICT=1 node build.mjs`, `node tools/check-i18n.mjs`, `node tools/check.mjs` — 0 ошибок, 0 предупреждений.

## Порядок

1. **Проверка сервера (ничего не меняет).** Любой пуш в ветку с изменениями в `wellness/` запускает в Actions задачу `check`: сборку и `./deploy.sh wellness-check`. Прочитать отчёт. Выкладка заблокируется сама, если:
   - `nginx -t` уже сейчас не проходит;
   - порт 80 держит не nginx;
   - нет конфига erkak.com или в нём нет `root /var/www/erkak.com;`, или домен описан в нескольких конфигах;
   - в `/var/www/erkak.com` незнакомые файлы или ссылка;
   - порт 8796 занят чужим процессом;
   - node старше 22.13, нет rsync или места.
2. **Выкладка — только тегом**, после того как отчёт проверки чистый:
   ```bash
   git tag deploy-wellness-$(date +%F) && git push origin deploy-wellness-$(date +%F)
   ```
   Скрипт: резервная копия в `/var/backups/erkak-wellness/`, загрузка в служебные папки, замена сайта одной операцией, nginx reload только после `nginx -t`. Затем проверка: `/ru/` отвечает 200, заявки проходят через nginx, **все остальные сайты сервера отвечают так же, как до выкладки**. При любой ошибке — автоматический откат. Порядок отката проверен на копии сервера.
3. **После выкладки проверить:**
   - https://erkak.com/ → выбор языка, `/ru/`, `/en/`, `/th/`, `/private/`, `/ring/`;
   - тестовое сообщение бота в Telegram-группе (скрипт шлёт его сам);
   - пробная заявка с `/ru/private/` → в группе приходит с 💎;
   - GA4 (G-83Z5HYT9SB): согласиться на cookie и увидеть себя в «Отчёты → В реальном времени»;
   - Search Console: добавить ресурс erkak.com, отправить `https://erkak.com/sitemap.xml`. Код подтверждения — в `SITE.verify.google` (`wellness/content/core.mjs`), пересобрать и выложить.

## Откат вручную

- Прежняя версия сайта: `/var/www/.erkak.com-prev`.
- Полные копии: `/var/backups/erkak-wellness/<дата>.tgz` (сайт, конфиг nginx домена, сниппет, `/opt/erkak-wellness`, служба). Распаковать: `tar -xzf <файл> -C /`, затем `nginx -t && systemctl reload nginx`.
