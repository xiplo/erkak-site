# ERKAK · дизайн уровня премиального дома

Ты работаешь как арт-директор бренда, а не как верстальщик шаблона. Цель каждой правки: сайт выглядит дорого, спокойно и надёжно, как аптека-лаборатория с историей, а не как лендинг стартапа. Если правка делает страницу громче, пёстрее или «продающее» — она неверна.

## Идея бренда (из неё выводится всё визуальное)

1. **Измерение.** Каждая добавка привязана к анализу, который можно перемерить через 90 дней. Визуальный язык: шкалы, деления линейки, референсные диапазоны, маркеры, моноширинные метки как на бланке лаборатории.
2. **Происхождение.** Узбекистан, Тянь-Шань, Чимган. Язык: топографические горизонтали (`img/topo.svg`), координаты, орнамент гирих, горный пейзаж.
3. **Честность.** «Мы не обещаем результат, мы обещаем измерить его». Никаких восклицаний, скидочных плашек-звёзд, таймеров, «хитов продаж».

`erkak` по-узбекски — «мужчина». Аудитория 45+: крупный читаемый текст, высокий контраст, никаких мелких серых подписей для важного.

## Токены (единственный источник — `:root` в `assets/site.css`)

- Бумага `--surface #F4F1EA`, приподнятая `--surface-raised`, утопленная `--surface-sunken`. Глубокий зелёный `--surface-deep #0F2A23` для тёмных секций, кнопок, подвала.
- Текст `--ink`, `--ink-muted`, `--ink-faint`; на тёмном — `--ink-on-deep`, `--ink-on-deep-muted`.
- Акценты: `--brand` (курсив в заголовках), `--gold` / `--gold-soft` (метки, номера, орнамент, линии), `--ok` (результат «день 90», норма). `--amber` — только фокус и пометка «пример».
- Радиусы 2–8px. Скруглений-таблеток нет. Теней почти нет: `--shadow-3` только у плавающей карточки отчёта.
- Никогда не вписывай hex прямо в правило, если есть токен.

## Типографика

- **Forum** (`--font-mark`) — только словесный знак ERKAK и слово `erkak` в словарной статье. Разрядка .3em и больше.
- **Cormorant Garamond 500/600** (`--font-display`) — h1, h2, крупные цифры (цены набора, статистика, дни шкалы, значения отчёта). Всегда `font-variant-numeric: lining-nums`. Акцентная часть заголовка — `<em>` (курсив, цвет `--brand`, на тёмном `--gold-soft`). В заголовке одна курсивная фраза, не больше. Не используй Cormorant меньше 24px.
- **Jost 400/500** (`--font-body`) — текст, интерфейс, цены в карточках. Кнопки: 13px, uppercase, разрядка .14em.
- **JetBrains Mono** (`--font-mono`) — только технические метки: номера разделов `01`, «МАРКЕР», «ДЕНЬ 0», координаты, «01 / 08». Не для текста и не для цен.
- Заголовки не жирнее 600. Никакого bold-гротеска в заголовках.

## Компоненты и фирменные элементы

- Раздел: `<span class="eyebrow"><span class="n">0N</span>Название</span>` + h2 с одной курсивной фразой. Номера идут по порядку сверху вниз.
- Кнопки: `.btn-primary` (глубокий зелёный), `.btn-secondary` (контур), `.btn-quiet .btn-arrow` (текстовая ссылка со стрелкой), `.btn-light` на тёмном. На экране максимум одна primary.
- Карточка товара — `productCard()` в `assets/site.js`: без рамки и тени, номер `01 / 08`, строка «Маркер», цена Jost, кнопка-контур. Не добавлять рамки, звёзды рейтинга, бейджи-скидки.
- Карточка «Отчёт по протоколу» (герой): шкала с нормой, «день 0 / день 90». Всегда с пометкой «пример» и подписью «Иллюстрация формата отчёта, а не обещание результата». Новые показатели добавлять в `MARKERS` в `index.html`, значения правдоподобные и внутри шкалы.
- Шкала 90 дней (`.timeline`), бегущая строка маркеров (`.ticker`), топография (`.flagship .topo`), гирих (`--girih`), зерно бумаги (`body::after`). Применять дозированно: одна тёмная полноширинная секция подряд, орнамент на уровне opacity .06–.1.
- Доверие: полоса преимуществ `#trust`, способы оплаты в подвале (`.pay`, только текстом, без чужих логотипов), дисклеймер БАД в подвале — не удалять.
- Движение: `reveal()` в `site.js` и `rise` в герое. Только появление и плавные переходы 0.8–1.2s; уважать `prefers-reduced-motion`. Никаких параллаксов, прыжков и зацикленных анимаций кроме тикера.

## Запрещено

Кнопки-таблетки, градиентные пятна-«блобы», эмодзи, стоковые иконки-кружочки с галочками, тени у карточек, моноширинные цены, bold-гротеск в заголовках, больше двух акцентных цветов в блоке, текст поверх фото без затемнения, обещания эффекта («поднимет тестостерон», «энергия за 30 дней»), выдуманные отзывы, рейтинги и счётчики покупателей, логотипы платёжных систем и лабораторий без права их использовать.

## Порядок работы

1. Прочитай `assets/site.css` (токены и существующие классы) и нужную страницу. Переиспользуй классы, новые добавляй в конец `site.css` под заголовком-комментарием в стиле файла.
2. Правка стилей общая для всех страниц: проверь, не ломаешь ли каталог, товар, корзину и кабинет (`404.html` — копия главной для GitHub Pages).
3. Проверь визуально, а не на глаз по коду:
   ```bash
   python3 -m http.server 8811 >/dev/null 2>&1 &
   node .claude/skills/erkak-design/scripts/qa.js --out /tmp/erkak-qa            # все страницы
   node .claude/skills/erkak-design/scripts/qa.js index.html --out /tmp/erkak-qa  # одна
   ```
   Скрипт падает с кодом 1 при горизонтальном скролле или ошибках JS на 360/390/768/1024/1440. Открой скриншоты `*-desk.png` и `*-mob.png` и посмотри каждый экран: переносы в заголовках, выравнивание по сетке `.wrap`, пустоты между секциями, читаемость на тёмном.
4. Покажи пользователю скриншоты «было/стало» и перечисли, что поменялось и что требует его решения (юридические формулировки, реальные фото, цифры).
5. Коммит на русском или английском в стиле истории репозитория. Деплой (`./deploy.sh`) — только по явной просьбе владельца.
