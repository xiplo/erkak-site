# wellness/ · ERKAK на erkak.com

Мировая экосистема мужского велнеса: хаб, 14 направлений, топ-100 программ. Раздел рыбалки `/fishing/` уже продаётся, остальные программы — предзапись. Статический сайт и API заявок, без зависимостей.

- Стратегия экосистемы: [ECOSYSTEM.md](ECOSYSTEM.md)
- Рыбалка, ниша и конкуренты: [STRATEGY-fishing.md](STRATEGY-fishing.md)

## Структура
| Файл | Что внутри |
|---|---|
| `assets/eco.js` | Цели, регионы, 14 направлений, 88 программ (компактные строки), клуб, FAQ хаба |
| `assets/data.js` | Раздел рыбалки: контакты (общие для всего сайта), юрданные, курсы, 12 туров, карта, календарь, FAQ |
| `assets/art.js` | Логотип ERKAK, силуэты рыб, иконки направлений, фоны постеров |
| `assets/app.js` | Общее: меню, валюта, фильтры и квиз рыбалки, карта, UTM |
| `assets/eco-app.js` | Хаб: каталог топ-100 (поиск, цели, регион, бюджет, хиты), квиз «цель → 3 программы», предзапись |
| `assets/erkak.css` | Дизайн-система |
| `build.mjs` | Генерирует всё ниже |
| `server/leads.mjs` | Заявки: SQLite, Telegram, CLI-воронка |

Что генерирует `build.mjs`:
| Путь на сайте | Страница |
|---|---|
| `/` | Хаб |
| `/d/<направление>.html` | Страницы направлений (13) |
| `/p/<программа>.html` | Страницы программ (88) |
| `/fishing/`, `/fishing/tours/*.html` | Раздел рыбалки |
| `/privacy.html`, `/404.html`, `sitemap.xml`, `robots.txt` | Служебные страницы и SEO |

Все ссылки абсолютные от корня домена. Правьте `eco.js`, `data.js` или `build.mjs`, потом запускайте `node build.mjs`.

**Добавить программу:** одна строка в `ECO.products`:
```
[id, направление, регион, название, где, длительность, от $, коротко, хит 1/0]
```
Если программ станет не 100, сборка предупредит.

**Открыть продажи по направлению:**
1. Поставьте `status:'live'` у направления.
2. Перенесите его программы в полноценный формат, по образцу туров рыбалки.

## Локально
```bash
cd wellness
node build.mjs
STATIC_DIR=. node server/leads.mjs      # http://localhost:8796 — сайт и API
```

## Деплой на erkak.com
```bash
./deploy.sh wellness      # из корня репозитория
```
Команда делает следующее:
1. Кладёт статику в `/var/www/erkak.com`. Магазин переносится в `/var/www/erkak.com-shop`.
2. Кладёт API заявок в `/opt/erkak-wellness` (systemd `erkak-wellness`, порт 8796).
3. Подключает nginx-сниппет с `location = /api/lead`. Перед правкой конфиг сохраняется в `.bak`, TLS не трогается.

Вернуть магазин: `./deploy.sh vps`. Пока на домене экосистема, API магазина `erkak-api` не перезапускайте: он читает `catalog.js` из корня сайта.

Если API недоступен, заявка не теряется: клиенту открывается Telegram или WhatsApp с готовым текстом.

## Заявки
Файл `/opt/erkak-wellness/.env`:
```
TELEGRAM_BOT_TOKEN=
LEADS_TG_CHAT=
```

Типы заявок:
| Тип | Откуда |
|---|---|
| `eco` | Квиз хаба |
| `waitlist` | Предзапись на программу |
| `quiz` | Квиз рыбалки |
| `tour` | Форма тура рыбалки |

Команды:
```bash
cd /opt/erkak-wellness
DATA_DIR=data node leads.mjs list 20
DATA_DIR=data node leads.mjs status 12 quoted "3 варианта отправлены"
DATA_DIR=data node leads.mjs stats        # воронка, источники, спрос по программам — основа решения, что запускать следующим
```
