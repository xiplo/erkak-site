# wellness/ · ERKAK на erkak.com

Мировая экосистема мужского велнеса на шести языках: 14 направлений, топ-100 программ, 14 мест, 9 гайдов. Раздел рыбалки уже продаётся, остальные программы работают как предзапись.

Сайт статический и генерируется одним скриптом, API заявок работает на Node 22. Внешних зависимостей нет.

Стратегия:
- экосистема: [ECOSYSTEM.md](ECOSYSTEM.md);
- рыбалка, ниша и конкуренты: [STRATEGY-fishing.md](STRATEGY-fishing.md);
- правила перевода: [content/TRANSLATING.md](content/TRANSLATING.md).

## Как устроено

| Путь | Что внутри |
|---|---|
| `content/core.mjs` | Общие данные для всех языков: направления, 88 программ, 12 туров рыбалки, места, споты, сезоны, гайды, цены, курсы валют, контакты, языки |
| `content/<язык>/` | Только тексты: `ui` (интерфейс, склонения), `catalog`, `fishing`, `site` (главная, о нас, документы), `guides`. Эталон — `ru` |
| `lib/i18n.mjs` | Строки, склонения (`Intl.PluralRules`), деньги, длительности, месяцы |
| `content/photos.mjs` | Фото: ключ → кадр, размер, BlurHash. Сейчас временная подборка Unsplash |
| `lib/art.mjs` | SVG-спрайт: знак ERKAK (вершина «Λ» в скруглённом квадрате), 11 рыб, глифы, иконки. Карта Андамана |
| `lib/photo.mjs`, `lib/blurhash.mjs` | `<img>` с `srcset` и размытой подложкой из BlurHash; локальные файлы, если они есть, иначе CDN |
| `lib/site.mjs` | Каркас страницы (`head` с hreflang, OG, JSON-LD), шапка, подвал, карточки, формы, «Мой маршрут» |
| `lib/pages.mjs` | Шаблоны страниц: главная, рыбалка, тур, направление, программа, места, место, гайды, гайд, о нас, документы |
| `src/css/erkak.css` | Дизайн-система: белый и тёплый светло-серый фон, графит как единственный акцент, цвет дают фото. Капсульные кнопки, скруглённые карточки, один шрифт Golos Text (арабский — IBM Plex Sans Arabic), RTL через логические свойства |
| `src/js/` | `core.js` (шапка, валюта, подсказка языка, UTM, заявки, маршрут), `catalog.js`, `quiz.js`, `fishing.js` |
| `src/fonts/` | Свои шрифты. Google Fonts не используется: это требование GDPR, и в Китае этот сервис недоступен. Китайская версия использует системные шрифты. Шрифты обновляет `tools/fonts.mjs` |
| `src/img/` | Иконки, favicon, OG-картинки 1200×630 (`tools/og.mjs`) |
| `build.mjs` | Сборка всего сайта в `public/` |
| `server/` | API заявок (`leads.mjs`), systemd-юнит, nginx-сниппет |
| `tools/` | Проверки (`check.mjs`, `check-i18n.mjs`), генераторы (`og.mjs`, `fonts.mjs`), `indexnow.mjs` |

### Адреса

| Путь | Страница |
|---|---|
| `/` | Выбор языка (x-default): сохранённый язык или язык браузера |
| `/{ru,en,de,ar,zh,uz}/` | Главная на каждом языке |
| `/{яз}/fishing/`, `/{яз}/fishing/<тур>/` | Раздел рыбалки и 12 туров |
| `/{яз}/<направление>/`, `/{яз}/<направление>/<программа>/` | 13 направлений и 88 программ |
| `/{яз}/destinations/…`, `/{яз}/guides/…` | Места и гайды |
| `/{яз}/about/`, `/terms/`, `/privacy/` | О нас (там же визовая поддержка) и документы |

Слаги английские и одинаковые во всех языках, поэтому hreflang связывает страницы один к одному.

Что генерируется помимо страниц:
- `sitemap.xml` (индекс) и `sitemap-<яз>.xml` с `xhtml:link`;
- `robots.txt`, `llms.txt`, `manifest.webmanifest`;
- ключ IndexNow;
- многоязычный `404.html`.

Все CSS и JS получают хеш в имени (`/assets/<имя>.<хеш>.<ext>`), поэтому их можно кэшировать на год.

## Команды

```bash
cd wellness
node build.mjs                 # все языки → public/
node build.mjs --lang=ru       # один язык, быстро
node tools/check-i18n.mjs      # переводы против ru: ключи, длины списков, подстановки, ссылки, кириллица
node tools/check.mjs           # собранный сайт: ссылки, якоря, hreflang, title/description, canonical, JSON-LD, карты сайта
STATIC_DIR=public node server/leads.mjs   # http://localhost:8796: сайт и API заявок
node tools/og.mjs              # перерисовать OG-картинки и иконки (нужен Playwright)
node tools/fonts.mjs           # перекачать шрифты (нужен интернет)
node tools/photos.mjs          # скачать фото из content/photos.mjs в src/img/photos/ (нужен интернет)
```

Если язык ещё не переведён или перевод не собирается, сборка его пропускает и пишет предупреждение. При `STRICT=1` (так работает деплой) такой язык считается ошибкой.

## Как править

- **Текст:** правьте `content/<язык>/…`, затем `node tools/check-i18n.mjs <язык>`.
- **Цена, сезон, длительность, статус:** правьте `content/core.mjs`, это сразу меняется на всех языках.
- **Новая программа:**
  1. Добавьте строку в `PROGRAMS` в `core.mjs`: `[id, слаг, направление, место, длительность, от $, месяцы, хит, за что]`.
  2. Добавьте тексты с этим `id` в `catalog.programs` каждого языка.
  3. Проверка покажет, где тексты пропущены.
- **Открыть продажи направления:** поставьте `status:'live'` у направления в `core.mjs`, тогда кнопки «Предзапись» станут бронированием.
- **Новый язык:**
  1. Добавьте его код в `SITE.langs`.
  2. Скопируйте папку `content/en` в `content/<код>` и переведите по `content/TRANSLATING.md`.
  3. Если нужен другой алфавит, добавьте шрифт в `tools/fonts.mjs`.

## Деплой на erkak.com

```bash
./deploy.sh wellness      # из корня репозитория
```

Что делает команда:
1. Собирает все языки в строгом режиме и прогоняет обе проверки. Если есть ошибки, деплой останавливается.
2. Выкладывает `wellness/public/` в `/var/www/erkak.com`. Магазин переезжает в `/var/www/erkak.com-shop`.
3. Выкладывает API заявок в `/opt/erkak-wellness` (systemd `erkak-wellness`, порт 8796).
4. Подключает nginx-сниппет:
   - `location = /api/lead`;
   - кэш `/assets/` на год;
   - `404.html`.

   Если с конфигом сервера возник конфликт, сниппет откатывается. Перед первой правкой конфиг сохраняется в `.bak`.
5. Отправляет все адреса в IndexNow (Bing, Yandex, Seznam). Отключить: `NO_INDEXNOW=1`.

Вернуть магазин: `./deploy.sh vps`.

Если API недоступен, заявка не теряется: клиенту открывается Telegram или WhatsApp с готовым текстом.

## Заявки

Файл `/opt/erkak-wellness/.env`:
```
TELEGRAM_BOT_TOKEN=
LEADS_TG_CHAT=
```

Типы заявок:

| Тип | Откуда |
|---|---|
| `eco` | Квиз главной |
| `waitlist` | Предзапись на программу |
| `plan` | «Мой маршрут»: несколько программ одной заявкой |
| `quiz` | Квиз рыбалки |
| `tour` | Форма тура рыбалки |
| `guide` | Гайд по Андаману |

У каждой заявки сохраняются язык сайта, валюта, страница и UTM-метки.

```bash
cd /opt/erkak-wellness
DATA_DIR=data node leads.mjs list 20
DATA_DIR=data node leads.mjs status 12 quoted "3 варианта отправлены"
DATA_DIR=data node leads.mjs stats            # воронка, источники, туры, языки за 30 дней
DATA_DIR=data node leads.mjs export 90 > leads.csv
```

## Подтвердить до запуска

Сейчас в данных стоят заглушки и черновики.

- **Фото.** Сейчас это временная подборка из Unsplash (лицензия разрешает коммерческое использование без подписи), кадры грузятся с CDN Unsplash. Перед запуском:
  1. Замените кадры на свои или сгенерированные: поменяйте `src` в `content/photos.mjs` или положите файлы `src/img/photos/<ключ>-<ширина>.webp`.
  2. Выполните `node tools/photos.mjs`, чтобы фото раздавались с erkak.com. Это важно для GDPR (немецкая версия) и для Китая.
  3. Выполните `node tools/og.mjs`: картинки для соцсетей перерисуются с настоящими фото. Без доступа к фото там будет размытая подложка.

- **Контакты в `content/core.mjs` → `SITE.contacts`.** Telegram `erkak_world` и WhatsApp `66000000000` — заглушки. WeChat пустой, поэтому нигде не показывается.
- **Реквизиты в `SITE.legal`:**
  - оператор;
  - лицензия TAT;
  - страховщик.

  Пока поля пустые, на сайте нет строки «Лицензия TAT № …».
- **Юридические тексты.**
  - Условия и политика конфиденциальности помечены как черновик.
  - Для немецкой версии нужны Impressum и полная Datenschutzerklärung (DSGVO).
- **Цены программ.** Это ориентир по рынку на сентябрь 2026 (партнёр плюс сервис). Перед продажей сверьте их с партнёрами.
- **Условия клуба ERKAK.**
  - Уровни: $490 и $4 900.
  - Скидки: −10% и −15%.
- **Гарантии.** Сюда входит отмена тура рыбалки бесплатно за 7 дней.
- **Языки консьержа.** На сайте обещаны русский, английский и узбекский. Немецкий, арабский и китайский нигде не заявлены. Если появятся сотрудники с этими языками, обновите тексты по `TRANSLATING.md`.
- **Аналитика и верификация.** Заполните `SITE.analytics` (Метрика, GA4) и `SITE.verify` (Яндекс, Google, Bing). Если включите аналитику для посетителей из ЕС (немецкая версия), нужен баннер согласия на cookies.
- **Решения переводчиков.** Всё это легко поправить в `content/<язык>/`.
  - В en, de, ar и zh договор и счёт обещаны «на английском», в uz — «на русском».
  - В zh вместо «企业发票» (китайская налоговая фапяо, которую ERKAK выдать не может) стоит «企业账单 / 对公账单 (Invoice)». Вместо USDT указан «美元付款».
  - В en и zh на страницах о России добавлено: «правила въезда зависят от паспорта — мы проверим». В zh у ДНК-теста есть примечание о вывозе образцов.
  - В uz в гайде о ретритах указан номер скорой в Узбекистане: 103.
  - Арабская версия не продвигает алкоголь и вечеринки: «мальчишник» стал «поездкой с друзьями перед свадьбой».
